# Launch checklist (before delivery)

- [ ] Reference studied; `work/launch/reference/breakdown.md` written
- [ ] `src/beats.json` complete: beats, frames, copy, colours, transitions, UI notes
- [ ] Bench plays cleanly (`ea launch stills --comp Bench`)
- [ ] UI demos ≥ half the film (aim ¾); each has 12+ UI animations (listed)
- [ ] `ea launch audit <p> --motion`: no errors, no frozen windows
- [ ] Stills sweep every 6 frames: no frame without readable text
- [ ] Titles settle ≥ 1 s; nothing needs a pause to read
- [ ] Sentence case; one accent word per line
- [ ] Only brand colours and fonts; special glyphs present
- [ ] Cursor never on a label; no numbers mid-roll on holds
- [ ] Transitions elastic and landing on the music
- [ ] Background calm; foreground carries the energy
- [ ] Music composed (or re-fit) to the cut; voice explains; an effect on every action
- [ ] `ea launch render`: −16 LUFS, true peak < −1 dBTP, frame count right, verify sheet looked at
- [ ] Formats rendered and checked: 16:9 master, 1:1 or 4:5 feed, 9:16 story
- [ ] Previous cut kept (`output/`) before any big change; brand saved to `<memory>/styles/`
