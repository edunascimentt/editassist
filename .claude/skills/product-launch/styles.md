# Same playbook, different films

Reuse the PROCESS, never the look: each product gets a visual idea taken from what it does.

- **Signet** (approvals / fintech): pastel floods, big friendly sentence-case type, blob cursor,
  elastic wipes, a green mascot, phone PIN approvals. The template's default language.
- **Danfo Rush** (browser game, 32 s, 4K): a real 3D world in three.js inside Remotion
  (`npm i @remotion/three three @react-three/fiber` in `launch/`), a night city with rain, neon lanes, buses, and a
  camera that always flies forward; the left third kept calm for headlines. Beats: headline scrambles
  in with an RGB split and lands crisp, a neon highlight block slams in behind the key word, and a HUD
  panel with bracketed corners shows live, ticking data; datamosh tears between beats. Free second
  version: swap only palette, sky and lighting (daylight) and export both.
- **Resolve** (support suite, 76 s, 4K): the REAL product UI. Capture each screen state from the HTML
  prototype at 2x (browser tools: screenshot + the container's HTML; search the file for class names,
  never read it whole), then rebuild layout, copy, spacing, radii, colours and type weights faithfully,
  scaled up to read on a phone. Own language: titles styled as chat messages with "Delivered" ticks,
  chat-bubble transitions, a pointer cursor instead of a blob, one dark night-time beat.

Your second film must not copy your first: change the title treatment, the cursor, the transition
family and add one beat that breaks the palette rule on purpose (like Resolve's dark beat).
